# Super Mona

Run, jump and stomp through 32 side-scrolling stages as Mona in this original platformer for the Universe 2026 badge.

## How to play

Reach the flag at the end of each stage before the timer runs out. Collect
floating stars (100 stars earns an extra life), bump `?` blocks for power
chips, sparkles and 1-ups, and stomp bugs and shellbots. Kick a shellbot's
shell — or hold **B** to pick it up and release **B** to throw it.

Leave the title screen idle for 10 seconds to watch a demo: a bot plays two
stages, collecting stars, while **PRESS SELECT** flashes. Any button returns to
the title, and **Select** starts a game. Demo play never touches your score or
high score.

## Stages

Eight worlds of four stages each. Every world follows the shape of a classic
NES world (overworld, underground, sky, castle), but the layouts are original.
Later worlds have wider pits and more enemies.

| World | -1 | -2 | -3 | -4 |
| --- | --- | --- | --- | --- |
| 1 | HELLO WORLD | SERVER ROOM | SKY BRIDGE | FIREWALL |
| 2 | PULL REQUEST | OVERFLOW | CLOUD DEPLOY | CONFLICT |
| 3 | CLONE | FORK | PUSH | PULL |
| 4 | ACTION | TRIGGER | PRE-PROD | PROD |
| 5 | BUG BASH | STACK TRACE | BREAKPOINT | SEGFAULT |
| 6 | CONTAINER | KERNEL PANIC | EDGE CACHE | DEADLOCK |
| 7 | CLONE | STASH | PR | MERGE |
| 8 | PLAN | BUILD | TEST | SHIP-IT |

## Controls

The capacitive pads follow a Game Boy-style layout.

| Pad | Action |
| --- | --- |
| D-pad | Move Mona (Down crouches when big) |
| Select (A) | Jump — hold for a higher jump |
| Back (B) | Run; hold to pick up a shell, release to throw it |
| Menu (Start) | Pause |
| Home | Quit to the menu |

The pause screen has four pages; use **Left/Right** to switch between them:

- **PAUSED**: score and high score.
- **MAP**: an overview of the stage showing where you are.
- **ITEMS**: power chips collected while already big are stored here (up to
  three). Use **Up/Down** and **A** to use one.
- **HERO**: swap between Mona and Ducky, a classic yellow rubber duck, with **Select**
  on every stage after 1-1. Ducky jumps higher but has less
  grip.

Press **Menu** or **B** to resume.

## Notes

- Runs in LORES (160x120) for a smooth frame rate; no network or extra
  hardware is needed.
- The high score is saved with `badgeware.State`.
- Tile and enemy art is generated by `tools/build_super_mona_assets.py`; the
  Mona sprites are derived from the Flappy Mona frames; Ducky is drawn in the
  same script.
